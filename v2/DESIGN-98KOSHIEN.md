# ぐにゃ野球 × '98甲子園 寄せ設計メモ（2026-11-02）

出典：'98甲子園ディープリサーチ（~/workspace/research_notes/98-koshien-game-systems-20261102-0233/report.md、出典つき）

## 原典の確定事実（要点）
- '98甲子園（1998年6月18日、PS、魔法株式会社、5,800円税別）。シリーズ6作目。'98本作はゲームアーカイブス未配信。
- プレイヤーは監督ではなく「自分で作った主人公球児本人」。入学→新入部員→レギュラー→キャプテンと立場が上がり、采配権が広がる。枠組みは高校3年間。
- 母校は全国4,129校（公称）から選択、実在校名も表示可。地方予選→甲子園、優勝・連覇が目的。
- 大会期間以外は練習。練習は7種類（投球・バッティング・シートノック・盗塁・ランニング＋2種未確認）のミニゲーム形式で、結果をマネージャーが評価し成長に直結。
- 試合はアクション操作主体（投打・守備・走塁）。采配はオーダー、代打・代走、投手の疲れを見た交代、作戦。
- カルト要素：投球モーションエディット（3秒以内＋一部接地のみ、パラパラマンガ式）、校歌エディット、校旗ドット絵、実況=古谷徹・解説=加藤精三。学校ごとに打撃型/機動型/守備型などのチーム特性。
- 原典に無いもの：ガチャ相当の選手獲得、名門度・資金・設備システム、育成素材、スタミナ（いずれも出典なし＝未確認/不存在）。疲労・怪我は前作Vの仕様としての明記のみ。

## ぐにゃ野球への移植マッピング（設計案）
| '98甲子園の要素 | ぐにゃ野球での形 |
|---|---|
| 高校3年間の枠組み | シーズン制を「学年」に読み替え。3シーズン＝1世代、卒業で世代交代 |
| 毎年4月の新入部員 | ガチャ（スカウト）の意味づけを「新入部員募集」に変更。排出プールは1年生として加入 |
| 主人公球児（自作） | マイ選手1人を手作り（名前・守備位置・投打）し、3年間ずっと育てる核にする |
| 卒業 | 3年経過した選手は引退（殿堂入り記録として残す）。世代交代が自然なリセットになる |
| 練習ミニゲーム7種 | 既存の練習モードを練習メニュー化し、成績で経験値効率が変わる |
| 投球モーションエディット | 既存のモーション調整（腕の振り・リリース等）を「投球フォームエディット」として前面に出す |
| チーム特性（打撃型/機動型/守備型） | 自チームに特性を1つ選び、補正に反映 |
| 地方予選→甲子園 | リーグ戦の上位構造として「夏の大会」トーナメントを追加する余地（要検討） |
| 校歌・校旗エディット | 将来のUGC枠。初期は対象外 |

## ガチャ（新入部員スカウト）の仕様たたき台
- 位置づけ：毎「年度」の始まりに強く推すが、実行自体は常時可（現行スカウトと同じ）。
- 排出選手は全員1年生として加入し、初期能力は控えめ、成長上限（潜在）が高い個体を★で表現するなど、既存の排出率（★4=3%/★3=12%/★2=35%/★1=50%）は維持。
- 天井50回、10連の★3以上確定枠は現行仕様を踏襲。
- 卒業した選手の重複排出など、世代交代とガチャの整合は実装時に詰める。
