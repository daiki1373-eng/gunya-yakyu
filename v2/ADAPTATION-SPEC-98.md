# ぐにゃ野球 '98甲子園準拠 構成仕様（2026-11-02 指揮決定）

## 原典から徹底的に真似るポイント（構成）
1. **主人公球児が中心**：プレイヤーは監督ではなく、自作した主人公1人を入学から3年間育てる。立場は新入部員→レギュラー→キャプテンへ。
2. **高校3年間が枠組み**：1年＝1サイクル。3年終了で主人公世代は卒業し、次の世代（新しい主人公）へ。
3. **母校を選ぶ**：学校ごとにチーム特性（打撃型／機動型／守備型）があり、育成と補正に影響する。
4. **大会期間以外は練習**：日常は練習、勝負は大会。地方予選を勝ち抜くと甲子園本大会。優勝・連覇が目的。敗退したらその年度は終わり、進級へ。
5. **練習はミニゲームで、結果が成長を決める**：マネージャーの評価コメントが高評価ほど伸びが良い。パラメータは上がることも下がることもある（下方変動は段階Bで検討）。
6. **試合はアクション操作＋采配**：オーダー、代打・代走、投手の疲れを見た交代。← ぐにゃ野球の現行エンジン（アクション＋オート守備＋交代）がそのまま担う。
7. **上級生は卒業する**：選手には学年があり、年度末に進級、3年生は卒業（引退）。卒業生は殿堂（卒業生記録）に残る。
8. **投球フォームエディットが名物**：既存のモーション調整を「投球フォームエディット」として前面に出す（段階B）。

## 段階A（今回の実装範囲）：構成の骨格
- **主人公作成**：初回起動時（および世代交代時）に、名前・守備位置・投打（右投右打など）・背番号を決めて主人公カードを1枚作る。主人公は所持カードに「主人公」印つきで入り、卒業まで必ず在籍する（重複変換・引退の対象外）。
- **学校選択**：主人公作成と同時に母校を選ぶ。架空の学校名リスト（12校、各校に都道府県と特性つき）から選択。実在校名は使わない。チーム特性は補正に反映（打撃型=長打系+、機動型=走力系+、守備型=守備系+。数値は補正関数経由で控えめに）。
- **学年**：全選手カードに学年（1〜3）を持たせる。新規スカウト排出は全員1年生。既存セーブの所持カードは2年生として移行する（あと2年で卒業）。主人公は作成時の学年1年生。
- **年度カレンダー**：1年度＝地方予選（3試合の勝ち抜き）→甲子園本大会（3試合の勝ち抜き）→年度終了処理。予選で負けたら甲子園へは進めず年度終了。甲子園優勝が最大目標、連覇数を記録する。
  - 既存の6球団リーグは主モードから外し、大会構造に置換する（リーグ画面は大会画面に置き換え。リーグのコードは FEATURES で無効化し、保存のリーグ結果は新構成では使わない）。
  - 大会の相手は架空の高校をシード生成（学校名・総合力は年度とラウンドで決まる）。試合は現行エンジン（3回制）をそのまま使う。
- **年度終了処理**：全選手が進級（1年→2年、2年→3年）。3年生は卒業し、所持から外れて卒業生記録（名前・学年時の成績サマリ・卒業年度）に残る。主人公が3年生を終えたら世代終了：卒業式画面→新しい主人公作成へ（財布・解禁・卒業生記録・通算記録は引き継ぐ）。
- **保存**：v2スキーマに school / protagonist / calendar / grades / graduates を追加（既存の保存堅牢化・開発キーの枠組みを維持）。既存セーブ読込時は不足分を初期化し、所持カードへ学年2年を付与する移行を1回だけ行う。

## 段階B'（最優先に格上げ、2026-11-02）：対戦仕様そのものの'98式化＋動画の名物要素
根拠：ユーザーが送ったTikTok動画（@c_stanley_7g_1103、校歌ネタ）自体が'98甲子園のプレイ動画だった（コメント欄の「98甲子園」回答、外野フェンスのMAGICAL看板、校歌エディット・投球フォームの特徴で特定）。対戦の手触りと、動画で映える名物要素を再現する。

### 対戦の操作・判定
- 打撃：打者を左右に動かして（スライド/ドラッグ/ボタン）ボールをバットの芯で捉える方式。芯とのズレで打球の質（芯=強い打球、外角かすり=弱いゴロ等）が変わる。現行のタイミング判定と組み合わせる。
- 投球：球種選択後にストライクゾーン内の狙い位置を決めて投げる（タップで狙い指定）。変化球は狙いから変化して到達する。
- 走塁・盗塁：盗塁と進塁は連打入力（連打ボタン）で走力を出す。連打量と走力能力で成功率が変わる。
- 投手の疲労：球数で蓄積し、球速・制球に段階的に効く。疲労度は試合画面に表示し、交代の判断材料にする。回復は試合間（日程進行）で。
- 采配：試合中に代打・代走・投手交代、作戦（バント・盗塁・エンドラン）を使える。
- 練習は試合と同じ操作体系（打撃練習=動かして芯、投球練習=狙い、盗塁練習=連打）にし、終了時にマネージャーの評価コメント（3段階以上）で経験値効率が変わる。

### 動画の名物要素
- 投球フォーム：既存モーション調整に加え、大げさなプリセットフォーム（開脚・回転・土下座風など、コメディ表現に限定し実在の人物・球団とは無関係の名称）を選べるようにする。フォームは見た目とモーション補正にのみ影響。
- 勝利後の校歌斉唱：大会の試合に勝つと、選手が横一列に並ぶ斉唱シーンを出す。校歌は短いメロディ候補から選べる（作曲エディットは将来枠）。校名も表示する。
- 試合表示：S・B・Oと走者ダイヤモンドを画面左上に常時表示（原典・動画のレイアウト）。
