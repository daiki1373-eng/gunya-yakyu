# ぐにゃ野球 プライバシーポリシー

最終更新：2026年11月2日

ぐにゃ野球は、ログインせずに遊べるオフラインの野球ゲームです。

ゲームの進行、作成した選手、成績は端末内に保存します。iPhone版では、端末内の保存領域にもバックアップします。これらのデータを開発者のサーバーへ送信する機能はありません。端末間の自動同期には対応していません。

広告SDK、アクセス解析SDK、広告識別子を利用した追跡は組み込んでいません。位置情報、連絡先、写真、カメラ、マイクへのアクセスも行いません。

アプリを削除すると、アプリ内に保存したデータも失われます。端末のバックアップや復元については、利用するOSの設定と仕様に従います。

不具合やお問い合わせは、[GitHubのサポート窓口](https://github.com/daiki1373-eng/gunya-yakyu/issues)で受け付けます。投稿内容はGitHub上で公開されるため、パスワードや個人情報を投稿しないでください。サポート窓口の利用には、GitHubのプライバシーポリシーが適用されます。

データの扱いに変更が生じた場合は、このページを更新します。
