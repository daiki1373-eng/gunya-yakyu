# 甲子園V（PlayStation, 1997, 魔法株式会社）試合中操作仕様シート
## ― HTML5 Canvas 再実装のための設計書 ―

調査日: 2026-11-02 / 対象: 『甲子園V』（こうしえん5、1997年5月16日発売、定価5,800円税別、SLPS-00729、シリーズ第5作、2011年3月25日にゲームアーカイブス配信）

### 確度ラベルの凡例（本書全体で使用）
- **【確認】** … 複数の出典、またはゲーム画面そのもの（スクリーンショット）で確認できた事実
- **【証言】** … プレイ動画内のプレイヤー発言・自動字幕に基づく。 gist（要旨）は信用できるが細部は曖昧
- **【単一出典】** … 1つの出典のみ。採用するが割り引く
- **【矛盾】** … 出典間で食い違う。両論併記し、再実装での扱いを提案
- **【提案】** … 原作に数値の出典がない箇所について、再実装が動くようにこちらで設計した数値。**原作仕様ではない**
- **【未確認】** … 調査で証拠が得られなかった項目

> 重要な前提: 本作は「野球アクション」ではなく **「監督が1球ごとに作戦ボタンを押す、ほぼオート進行の試合シミュレーション」** である。プレイヤーが試合中にできることは打撃と投球だけ（守備はコンピュータ）【確認: Wikipedia】。この割り切りが全仕様の背骨になる。

## Summary（要約）

1. **投打共通の基本画面は1つだけ**: 本塁後方（捕手の後ろ）からの3D視点。打者が画面手前（右打者なら右側）に大きく、投手が中央奥に小さく写る。攻撃でも守備（投球）でもカメラは変わらない【確認: 動画サムネイル2点で目視】。
2. **打撃は「ミートカーソル方式ではない」**【確認寄り】。パワプロ式カーソルの存在を示す出典・画面は一切見つからなかった。代わりに **4つのボタンが「打法（作戦）」そのもの** ― □=ウエストボール打ち、△=ヒットエンドラン打ち、×=長打打ち、○=バント ― で、そこに十字キーの高さ／スイング軌道とタイミングを合わせる【確認: Wikipedia + ゲームカタログ@Wiki】。
3. **投球は「見えない狙い」方式**【確認】。十字キーでコースを決めるが **選んでいるコースは画面に表示されない**。投手ごとに割り当てられた4ボタンの球種を押して投げる。画面で確認できた球種配置例: △=STRAIGHT（速い方）、×=STRAIGHT（遅い方）、□=SCREW、○=CURVE、投手パラメータは SPEED（km/h）/ CONTROL の2値【確認: PITCHER SELECT画面】。
4. **守備・走塁は基本オート**【確認】。野手の移動・捕球は一切操作できない。捕球後の送球だけ操作できるかは【矛盾】（後述）。走塁の手動入力の証拠はなく、走者関連の手動要素は△のヒットエンドランが中心。
5. **演出の主役は音**: 本作から試合中実況（音声）が入り、ウグイス嬢がエディットした選手名をイントネーション付きで読み上げ、金属バットの快音と応援合戦がメーカーの売り文句だった【確認】。
6. **最大のゲームバランス要素は操作ではなく打順**: 打つかどうかは能力値より打順補正に強く依存する（9番の凡打者が4番で主砲化する）ことが攻略系出典で指摘されている【単一出典・複数プレイヤー証言と整合】。再実装でも再現推奨（§1.6）。

## Findings

### 1. 打撃操作

#### 1.1 ボタン割り当て【確認】
出典: Wikipedia「甲子園V」操作方法（https://ja.wikipedia.org/wiki/%E7%94%B2%E5%AD%90%E5%9C%92V ）、ゲームカタログ@Wiki（https://w.atwiki.jp/gcmatome/pages/5537.html ）

| ボタン | 打法 | 意味・効果（分かる範囲） |
|---|---|---|
| □ | ウエストボール打ち | 名称のみ【確認】。効果の詳細は【未確認】。ウエストボール（敬遠球・外し球）を打つための専用スイングと解釈されることが多いが断定できる出典なし |
| △ | ヒットエンドラン打ち | 打つと同時に走者がスタートする作戦スイング【確認: 名称から自明＋作戦ボタン体系】 |
| × | 長打打ち | 強振相当。事実上の通常／長打スイング【確認】 |
| ○ | バント | 構え→ボール到達時にもう一度○で当てる二段式【証言: 土方アーク動画、後述】 |
| 十字キー | 選手を動かす／高さ・軌道の調整 | 「十字キーで選手を動かすことも出来る」【確認: Wikipedia】。「ある程度の高さとタイミングを合わせる」【確認: ゲームカタログ@Wiki】 |

注意点:
- **専用の「通常ミート打ち」ボタンは出典に存在しない**。4ボタンすべてが作戦色の強い打法であり、「どのボタンで振るか＝どういう打球を狙うか」を選ぶ設計と読むのが自然【解釈】。
- 加藤純一の実況動画冒頭では、視聴者提供の操作方法として上記と同一の割り当てが読み上げられている（Wikipedia転載の二次情報だが、実プレイヤー間で共有されていた操作表である傍証）【証言: https://www.youtube.com/watch?v=5Yfb3rVJYT8 】。

#### 1.2 ミートカーソル: なし【確認寄り／否定証拠の積み重ね】
- 試合画面のサムネイル（甲子園球場・練習試合の2シーン）を目視した範囲で、**ストライクゾーン枠もミートカーソルも表示されていない**【確認: https://i.ytimg.com/vi/zSgKm9C4w_o/maxresdefault.jpg 、https://i.ytimg.com/vi/kyScB6M81nU/maxresdefault.jpg 】。
- 前作『甲子園4』（SFC）はパワプロ式カーソル方式だった（§6）ため、これは意図的な廃止とみられる。
- ただし次作『'98甲子園』には「ミートゾーン」が存在し「キャッチャーが常時表示されミートゾーンが見づらい」と評されている【出典: https://consoledictionary.com/games/22651 ※'98の話】。V→'98で（再）導入された可能性があり、**Vに小さなゾーン表示があった可能性を100%は否定できない**。再実装では「表示なし」を正とする。

#### 1.3 タイミング判定
- 「ジャストミート」「真芯」といった固有名詞の判定概念は **Vについては【未確認】**（パワプロには「真芯」があるが V の出典には出てこない）。
- タイミングの早遅が結果に効くこと自体はプレイヤー発言で裏付けられる: 「ちょっと早いよ、タイミングが」（加藤純一動画の自動字幕）【証言】、アカgames動画でも「タイミング、多分（早め）」等の発言【証言】。
- 打球方向の決まり方: **下キーを押し続けるとアッパースイングになる**【証言: CLAY動画 https://www.youtube.com/watch?v=7bJv3auDLmw 「アッパースイングするために下を押し続けないといけない」】。つまり十字キー上下は (a) 球の高さへの対応、(b) スイング軌道（アッパー⇔通常）の両方に使われると読める。引っ張り方向への偏り（早いタイミング＝引っ張り）も同動画の「引っ張りすぎちゃってんもん」発言から示唆されるが【証言・弱】、流し打ち専用操作は【未確認】。

#### 1.4 バントの二段式【証言】
土方アーク動画（https://www.youtube.com/watch?v=7HYKZgu5WSE ）: 「バントフォームでボール来たらまたバントのボタン押すんだ、これ。そういうシステムか」「上下できない…あ、できた」
→ 再実装仕様として採用する: **○1回目=バントの構え（打席表示がバント構えに変化）、ボールが本塁付近に来たタイミングで○2回目=実際に当てる**。構え中の十字キーで転がす方向／高さの微調整ができる可能性（「上下できた」発言）。

#### 1.5 打球の物理【提案】
原作の内部数値は一切公開されていない。Canvas実装では以下を初期値とする（物理ベース換算）:
- 投球到達時間 = 18.44m ÷ 球速。140km/h→0.47秒、125km/h→0.53秒、110km/h→0.60秒、90km/h（カーブ）→0.74秒【計算値】
- スイングタイミング窓【提案】: 理想到達時刻 ±50ms=芯ヒット圏、±110ms=ファウル／凡打圏、それ以外は空振り。×長打打ちは窓を0.7倍に狭め、芯時の飛距離を1.25倍。△ヒットエンドランは窓1.15倍・飛距離0.85倍で走者が投球と同時にスタート。
- 十字キー下保持=アッパー（打球角度+12°）、上保持=ダウンスイング気味（打球角度−10°、ゴロ率UP）【提案: §1.3の証言を数値化】

#### 1.6 打順補正（本作の魂）【単一出典＋整合証言】
ゲームカタログ@Wiki: 「選手が打つかどうかはステータスではなく打順に依存する所が大きい。20打数0安打の9番バッターでも4番に据えると20打数19安打5本塁打に早変わりする。ステータスの高い選手でも2番や下位打線では途端にポンコツになる」
→ 再実装【提案】: 打順係数テーブルを持つ（例: 3・4・5番=ミート/長打 ×1.3、1番=×1.1、2番=×0.8（バント寄せ）、8・9番=×0.7）。数値自体は原作値ではないが、この偏りを入れないと「甲子園Vらしさ」は再現できない。

### 2. 投球操作

#### 2.1 基本フロー【確認】
ゲームカタログ@Wiki: 「ピッチングは十字キーでコースを決め（選んでいるコースは見えない）、各ボタンに割り当てられた球種を投げる方式」
1. 十字キーで狙いを動かす（初期位置はゾーン中心。**狙いは不可視** ― '98の実況者証言「表示されないけど最初はストライクゾーンの中心に狙いがあって方向キーの入力に合わせて狙いが移動する」は同型システムの傍証【証言: https://www.youtube.com/watch?v=FfgoZBS1bbE ※'98】）
2. 球種ボタンを押すと即座に投球モーション開始。**タイミングメーター類は存在しない**【確認寄り: 出典・画面に一切なし】
3. 投球モーションは投手の（エディット可能な）フォームアニメーションがそのまま再生される

実効性への疑問も記録しておく: 「コースは一応方向キーの上下左右で決められるけど、変わってんのかいまいちわかんないし、あんまり効果ない気がする」（土方）【証言】。再実装では狙いの効きを弱め（ブレ量大）にすると原作の手触りに近づく【提案】。
