# ぐにゃ野球 サポート

ボールを投げ、タイミングを合わせて打つ。守備では送球先を選び、攻撃では走者を進めたり戻したりできます。

投球画面の「投球フォーム」から、構え・踏み込み・リリースの姿勢を編集できます。「回転・伸び」では、全身回転や腕の回転、胴の長さ、ジャンプを組み合わせて遊べます。フォームの変更は見た目だけで、今のプレイ中に有効です。

試合中の「Ⅱ」で一時停止できます。アプリをバックグラウンドへ移した時も、試合を止めます。戻ったら「つづける」を押してください。

セーブは端末内への自動保存です。別の端末への同期や、アプリ削除後の復元を保証する機能はありません。

不具合は[Issues](https://github.com/daiki1373-eng/gunya-yakyu/issues)へ、端末名、OS、起きた画面、操作手順を添えてお知らせください。
