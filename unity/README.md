# 甲子園への道（Unity版・フェーズ1試作）

HTML版「甲子園への道」を Unity に移植する試作プロジェクトです。
フェーズ1の範囲は「試合プロトタイプ」だけです：ラグドール（関節がぐにゃぐにゃ曲がる人形）の投手と打者で、「投げる → タイミングよくタップして打つ → 打球が飛ぶ」が遊べます。

- Unity のバージョン: **2022.3 LTS**（プロジェクトは 2022.3.62f1 で作成）
- 仕様の正は HTML 版 `landscape/claude-v.html`（このフォルダの外、リポジトリの `landscape/`）です。能力値・種族・球種・必殺技の数値は HTML 版から移植しています。

---

## 1. 用意するもの

1. **Unity Hub**（無料）: https://unity.com/ja/download からインストール
2. **Unity 2022.3 LTS 本体**: Unity Hub の「インストール」から追加
   - インストール時にモジュールを聞かれたら、まず必須なのは本体だけです
   - スマホブラウザ向けに出力したい場合は **「WebGL Build Support」** にもチェックを入れてください（あとから追加もできます）

## 2. プロジェクトの開き方

1. このリポジトリを Mac に取得します（GitHub Desktop でクローン、または GitHub のページから ZIP をダウンロードして解凍）
2. Unity Hub を開き、「プロジェクト」→「ディスクからプロジェクトを追加」で、この **`unity` フォルダ** を選びます
3. 一覧に出たプロジェクトをクリックして開きます
   - **初回は読み込みに数分かかります**（ライブラリを自動生成するため）。固まったように見えても待ってください
   - 開くときに、画面（シーン）が自動で作られます。何も表示されない真っ暗な画面ではなく、カメラだけのシーンが開けば正常です

> うまくいかないときは、Unity のメニューから **「甲子園への道」→「初期セットアップを実行」** を押してみてください。

## 3. 遊び方（再生）

1. Unity 上部の **再生ボタン（▶）** を押します
2. 操作は全部タップ（パソコンではマウスの左クリック）です
   - 待機中にタップ → **投球**
   - ボールが飛んでいる間にタップ → **スイング**（タイミングが合うと当たります）
3. 止めるときは、もう一度再生ボタンを押します

遊べる内容：
- 投手はパン太（パンダ、変化球タイプ）固定。カーブ／スライダー／フォークを投げ分けます
- 打者は カブト丸（カブトムシ、長打タイプ）→ ワンタ（イヌ、俊足タイプ）→ 主人公（人間）の順に交代します
- カウント（ボール／ストライク／アウト）と回、得点が進みます。四球・三振・ヒット・二塁打・ホームラン・ファウルがあります
- 画面左下の「必殺ゲージ」は表示だけの仮置きです（必殺技の実装はフェーズ2）

## 4. WebGL で出力する手順（スマホで試す用）

1. メニュー **File → Build Settings** を開く
2. 左の一覧で **WebGL** を選び、「Switch Platform」を押す（初回は少し時間がかかります）
3. 「Build」を押し、出力先にこのフォルダ内の **`build-webgl`** フォルダを指定する
4. 出来上がった `build-webgl` フォルダの中身を、そのまま静的ホスティング（GitHub Pages など）に置けばスマホのブラウザで開けます

※ `build-webgl` は自動生成される成果物なので、Git には入れていません（.gitignore 済み）。

## 5. エラーが出たとき

赤い文字のエラーが出て再生できないときは、**エラーメッセージをそのままコピーして、Muse（たんたん）に貼ってください**。

1. Unity 下部の **Console** タブを開く（なければメニュー Window → General → Console）
2. 赤いエラーの行をクリックすると、下に詳しい内容が出ます
3. その全文をコピーして貼ってもらえれば、こちらで直します

「どの操作で、どうなったか」も一言添えてもらえると早く直せます（例：「開いた直後にエラーが3つ出て、再生しても真っ暗」）。

## 6. 実装済み・未実装

実装済み（フェーズ1）:
- ラグドール選手（頭・胴・両腕・両脚を物理ジョイントで接続。関節は大げさに曲がります）
- 試合の最小ループ（投球→スイング→打球/空振り→次の打席）
- 判定は HTML 版の確率モデル（タイミング窓・芯の質・飛距離計算）を単純化して移植
- 球場の背景（観客席・スコアボード・広告看板・フェンス・芝と土・マウンド）
- 種族（カブトムシ／イヌ／パンダ）の見た目と能力補正、固有キャラ3名

未実装（フェーズ2以降）:
- 必殺技4種の効果（ゲージ表示のみ仮置き）
- 拠点・練習・育成・疲労・ケガ、地方予選〜甲子園の大会進行、世代交代
- セーブ（HTML 版との互換も含め未対応）
- ガチャ、オンライン対戦

## 7. フォルダ構成

|---|---|
| `Assets/Scripts/GameController.cs` | 試合ループ・判定モデル・UI |
| `Assets/Scripts/RagdollPlayer.cs` | ラグドール選手の生成と動作 |
| `Assets/Scripts/BackgroundBuilder.cs` | 球場背景の生成 |
| `Assets/Scripts/PlayerData.cs` | 能力値・種族・球種・必殺技のデータ（HTML 版から移植） |
| `Assets/Scripts/SpriteFactory.cs` | 画像素材なしで絵を作る道具 |
| `Assets/Scripts/Bootstrap.cs` | 空シーンでも起動できる仕掛け |
| `Assets/Editor/ProjectSetup.cs` | 初回に起動シーンを自動作成 |
| `Assets/Scenes/Main.unity` | 起動シーン（初回オープン時に自動生成されます） |
