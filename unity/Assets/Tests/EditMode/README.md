# EditMode のロジック検証

新しいパッケージを追加せずに実行できます。Unity を停止した状態でメニュー
`ぐにゃ野球 > 検証 > EditMode ロジックテスト` を実行してください。
成功時は Console に11項目の PASS、失敗時は例外と対象の条件が出ます。
PlayerPrefs のコイン・所持・交換pt・天井と Unity の乱数状態は finally で元に戻します。

対象:
- 正本CSVの101体・レア度33/27/20/12/7/2・ID重複・CSVの引用符
- 固定seed100万回の基礎確率（仕様に対する±0.2パーセントポイント）
- 天井49回/50回の境界と、別seed100万回の★4以上の最大間隔50回
- SECRETの重複交換10,000pt、最終1枚の保持
- コイン不足、300枚→15pt、10連購入、25ptスカウト、試合報酬の二重受取防止
- 得点、3アウト、攻守交代、先攻/後攻、最終裏省略、サヨナラ、引分け、盗塁/盗塁死
- 試合終了後の得点・アウト・走者の固定
- 大きなホームランのカメラ位置/注視点の境界（Unity EditModeのみ）

確率テストは `RollRarity`（天井前）を対象にしています。天井込みの★4排出率は
仕様の基礎3%より上がるため、同じ±0.2%判定に混ぜません。

既に NUnit を参照できる環境では `GUNYA_NUNIT_TESTS` を定義すると任意の
`NUnitAdapter.cs` が有効になります。このPRからはTest Frameworkを追加しません。

## Unity を起動しない検証

```sh
python3 unity/Tools/verification/verify.py
```

Unity 2022.3.62f1 のインストール済みMonoコンパイラ・実際のUnity DLLで、
プレイヤー用とエディタ用の全C#ソースを別々にコンパイルします。
その後、カメラ以外の10項目を小さなオフライン用ストレージ/乱数/Resourceアダプターで実行します。
アダプターはUnityの画面・物理・PlayerPrefs実装の検証を代替しません。
一時ファイルはOSの一時ディレクトリ内だけに生成し、終了時に削除します。
別のインストール先は `--unity /path/to/Unity.app/Contents` を指定できます。
