## 全体として Unity 側で吸収したこと

- **レア度と見た目の逆転**: 50体すべてが同じ「金×赤の豪華背景」で描かれていたため、★1 のモブが ★5 と同じくらい派手に見えていた。カード表示を「★1〜★3 は背景を抜いたキャラ＋レア度別の背景（★1 地味な紺 / ★2 銅 / ★3 青の放射）」「★4 以上は元の豪華な絵」に変更。ガチャ排出・図鑑・タイトルすべてに反映。
- **2系統の絵柄差**: ★1〜★3 は背景が揃ったことで、塗りと背景の豪華さの差がかなり目立たなくなった（線の太さの差は残る）。
- **審判おばちゃん（3コマ漫画）**: 試合とカード（★3）では一番下のコマだけを切り抜いて使用。
- **幽霊選手（半透明）**: 自動切り抜きが効かないため色で切り抜いて使用。

## 再生成プロンプト（要再生成 5体）

共通スタイル: 縦長 2:3、全身、金×赤の豪華な背景（放射状の光・花火・紙吹雪・キラキラ粒子）、大げさな表情とポーズ、笑える要素を1つ、**文字・ロゴ・数字・紙幣は入れない**、アニメ調で熱血おじさん（ojisan）の線の太さと塗りに合わせる。

1. **umpire（審判おばちゃん / ★3 / 捕手）**
   1コマの全身イラスト。黒いポロシャツの審判服に捕手マスクを頭にのせたおばちゃんが、キャッチャーミットを構えたまま、もう片方の手で力強く「アウト！」と指さし、ホイッスルをくわえて目を見開いている。腰に花柄のハンカチ。他のキャラクターは描かない。

2. **magical（自称・魔法少女 / ★3 / 外野手）**
   ステッキ型のバットで決めポーズをとるが、ステッキの先の星が取れかけて本人があわてている。フリルの衣装はひざ下丈、目線は正面か少し上から。泥はねと汗で「自称」感を出す。見上げる構図は使わない。

3. **idol（アイドル兼任選手 / ★4 / 外野手）**
   ライブ衣装のままユニフォームを羽織り、マイク型バットで全力スイングして空振りし、帽子が飛んでいく瞬間。汗だく、片方の靴が脱げかけ、髪は乱れている。可愛さより必死さを強調。背番号は入れない。

4. **ceo（社長選手 / ★3 / 内野手）**
   金色のバットに金の延べ棒と宝石をちりばめた成金スタイル。高笑いしながらバットを担ぎ、足元のアタッシュケースから金貨があふれている。紙幣は描かない。

5. **helper（外国人助っ人 / ★3 / 打者専門）**
   赤いユニフォームの金髪の大男が、片手でバット、片手で分厚い辞書を開いて首をかしげている。頭の上に「？」の吹き出し（記号だけ）。名札・文字は入れない。

## 判断が必要な「要修正」7体

dragon / legend-grandpa / robot-gold / snowman はポジションと絵の内容が違う。CSV（正本）を変えるか、絵を描き直すかの判断が必要。fisherman / fortuneteller / monk は絵としては使えるが、紹介文や方針と印象がずれている。
