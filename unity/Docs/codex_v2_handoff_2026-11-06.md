# ぐにゃぐにゃベースボール v2：コード側の改善とUnity確認事項

## 1. 結果

- 試合の登場・結果・攻守交代・走塁・リプレイを短縮。登場、結果待ち、走塁、盗塁、リプレイはタップでスキップできる。球速、スイング判定の時間窓、能力値は維持。
- 初戦は先攻、次戦は後攻。その後は交互。最終回表終了時の後攻リードでは裏を省略し、裏で勝ち越すとサヨナラ終了。`bgm-sayonara`を再生する。
- 完了した試合の勝敗・得点・安打・盗塁からコインを保存。二重受取を防止し、コインでの1回/10連、300枚→15pt、25ptスカウトを接続。
- 盗塁ボタン1個を追加。二盗・三盗と捕手送球によるアウトに対応。既存音源`bgm-steal-ok` / `bgm-steal-out`を使用（`bgm-steal`という音源は存在しない）。
- 重ね数を関節制限とスイング角速度へ反映。判定用の`PlayerStats`は変更しない。引き分けは自作の短い4音ジングルと結果表示で締める。
- 足元リングは自チームが赤、相手が青。攻守交代後もチームの色を維持。
- リプレイでは転倒、捕球、送球、走る人形も同じ速度にし、スキップ後に動きが残らないようにした。大きなホームランでは球場内の引きのカメラに切り替える。
- 体・顔の網目と重みをキャラ/解像度/骨構成ごとに再利用。画面外は変形を省略し、見える位置へ戻ったら更新する。同じ人形の画像を設定し直しても作り直さない。別キャラへの交代では骨を初期姿勢に戻してから接続する。
- キャラ画像の有無は50件の索引から判定し、一覧画像は表示範囲に入ったときに読む。継ぎ目用リストと花火の色配列を再利用。
- `Physics2D.IgnoreLayerCollision`を廃止し、生成したColliderの組ごとに体の衝突を除外。地面との衝突は残す。レイヤー行列の警告が消えたかはUnityで確認が必要。
- `AtBatController`を起動、打順、試合進行、入力、投球、走塁、登場、演出のpartialファイルに分割。ヒットストップ/スロー中にホームを開いても試合が勝手に再開しないようにした。
- EditMode検証とUnityを起動しないコンパイル・モデル検証を追加。新しいパッケージは追加していない。

確認済み：Unity 2022.3.62f1の実DLLによる全プレイヤー/エディタC#コンパイル（エラー・警告なし）、オフラインのモデル検証10項目、`git diff --check`。

100万回の基礎抽選：★1=49.0211%、★2=34.9777%、★3=11.9688%、★4=3.0105%、★5=1.0116%、SECRET=0.0103%。すべて仕様の±0.2パーセントポイント以内。別の100万回で★4以上の最大間隔は50回。天井込みの実排出率は基礎確率とは別に検証している。

## 5. 残課題

- 5分前後という試合時間、描画/物理/音、GC・メモリ改善量、レイヤー警告の消失はUnityでの実測待ち。コンパイルとモデル検証だけでは保証できない。
- 初めて必要になった画像は同期読込する。必要になった画像・重みキャッシュを後から破棄する上限管理は未実装。端末での計測結果を見て追加する。
- EditMode検証は追加パッケージ不要のメニュー実行方式。既にNUnit参照がある環境のみ`GUNYA_NUNIT_TESTS`で任意のアダプターを有効化できる。
- 再生成待ち5体、ポジション不一致7体、未画像51体、現行ラグドール仕様文言と元絵の体との整合は今回変更していない。
- ガチャ確率・50連天井・重ね上限・交換ポイント・CSV・キャラ方針は維持。変更は`unity/`のみで、禁止された設定・シーン・録画・元画像は含めていない。
