# ぐにゃ野球

## iPhone・横画面版（リリース候補）

光と影のある3D球場、投球フォーム編集、自動捕球と手動送球、走者の進塁・帰塁・停止に対応する版は `landscape/claude-v.html` です。同じゲームを `ios-app` のiPhoneアプリへ組み込みます。ビルド・実機確認・TestFlightの手順は [iPhone版ガイド](ios-app/IOS-GUIDE.md) を参照してください。署名・実機テスト・App Store公開は、それぞれ確認が必要です。

以下は既存の縦画面Web版の説明です。

物理演算で選手の関節がぐにゃっと崩れる、スマホ向けWeb野球ゲーム。
プロスピ寄りの見た目と、球種・変化のカスタム、モーション調整、リーグ進行、選手の収集・育成を備えたアプリ規模の構成。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（スマホ縦画面推奨）。進行状況はブラウザのlocalStorageに保存されます。

## 構成

- `index.html` — ゲーム本体（単一ファイル）
- `docs/gunya-yakyu-plan.md` — Claude Codeによる実装計画・検証チェックリスト
- `docs/gunya-core-draft.js` / `docs/gunya-shell-draft.html` / `docs/test-core.js` — 実装ドラフトと単体テスト（参考資料）

## 主な仕組み

- 球種7種＋変化の仕方・変化量のカスタム、投球・打撃モーションのスライダー調整
- 3回制の試合モード（守備はオート）、7チームのリーグ・シーズン進行
- 選手カードの収集・育成（スカウト、レベルアップ、先発編成が能力に反映）
- コイン経済、ミッション、ログインボーナス、設定変更時の広告表示（デモ）、デモ課金・プレミアムパス
- セーブデータはバックアップ保持・破損時の自動復元つき

広告と課金はデモ実装で、実際の決済・広告配信は行いません。
